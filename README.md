
# Diabetes Hospital Readmission Analysis

## Project Overview

This project aims to analyze hospital records of patients with diabetes to investigate the relationship between the number of diagnoses, length of hospital stay, and hospital readmission.

## Research Question

*Among patients with diabetes, is the number of diagnoses associated with length of hospital stay and readmission?*

## Dataset

**Dataset:** Diabetes 130-US Hospitals (1999–2008)

## How to Run the Project

### 1. Download the Repository

Clone the repository using Git or download it as a ZIP file from GitHub.

### 2. Install Dependencies

Make sure Python is installed, then install the required libraries:

```bash
pip install marimo pandas seaborn matplotlib
```

### 3. Open the Project Folder

Open the downloaded repository folder in VS Code or a terminal.

Make sure the notebook and CSV dataset are located in the same folder.

### 4. Run the Marimo Notebook

Enter the following command in the terminal:

```bash
marimo edit notebook.py
```

Replace `notebook.py` with the actual filename of the notebook.

The Marimo notebook will open in your browser, where you can run the analysis and view the visualizations.
